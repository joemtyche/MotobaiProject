BRANCH / WORKFLOW
- This branch is local-backend only.
- Any frontend-only/static-site work must happen in a separate branch.

PROJECT CONSTRAINTS
- The app in this branch runs locally with React frontend + Django/MySQL backend.
- Do not add frontend-only mode, backendless mode, or online backend deployment support here.

BIG FINDINGS / PRIORITY FIXES
- Order stock logic is risky:
  - OrderTracking can deduct stock on save while status is already validated.
  - Some serializer updates call order.order_tracking.save(), which can trigger extra stock changes.
- OrderDetails.save() appears broken:
  - It looks up OrderTracking by OrderDetails primary key.
  - It references self.status even though OrderDetails has no status field.
- Walk-in order deductions are likely ignored:
  - Frontend sends deduction.
  - Backend reads deductions.
- There are no meaningful backend tests yet.
- Admin models are not registered, so Django admin is not useful for inspecting app data.
- If a frontend-only static build is needed, make it in a separate branch.

DATA / LOCAL SETUP
- Use defaultdata/motobai_seed_local.sql instead of the original raw dump.
- Avoid importing django_migrations, django_content_type, and auth_permission from old dumps.
- Use backend/requirements.txt for local MySQL/MariaDB setup.
- Avoid Python 3.14 for backend local setup; use Python 3.11 or 3.12.

RECENTLY ADDRESSED
- Polished DynamicTable sorting:
  - Header cells now trigger sorting across the full cell.
  - Tables without edit handlers no longer call missing editRow callbacks.
  - Temporary rows without backend ids now fall back to their row index for keys/actions.
- Updated default table ordering:
  - Accounts, employees, walk-in customers, products, and suppliers default to ID order.
  - Inventory defaults to low stock, active, then inactive, with SKU ordering inside each group.
- Refined table columns and sorting:
  - Sort arrows now reserve fixed header space so clicking a header does not resize the table.
  - Inventory table no longer shows product description.
  - Products table now shows description immediately after product name.
  - Order Management and Order History can sort by order type and status.
- Re-enabled login/register for local frontend use.
- Added default frontend API URL fallback to http://127.0.0.1:8000.
- Fixed frontend refresh token endpoint to /api/token/refresh/.
- Made backend/requirements.txt local-only.
- Moved Django secret, debug, allowed hosts, CORS origins, and database connection settings to backend/.env.
- Restricted API data endpoints to authenticated users; registration and JWT token routes remain public.
- Moved frontend auth tokens from persistent localStorage to sessionStorage.
- Replaced live hardcoded frontend backend URLs with shared api wrapper routes.
- Removed dead commented frontend handlers that referenced hardcoded backend URLs.
- Added safer local SQL seed file.
